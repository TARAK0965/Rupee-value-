## 📂 Included Files in this Folder

1. **`index.html`**:
   - Clean, modern, accessible HTML5 semantic structure.
   - Screen automatically sized to display (responsive from mobile up to desktop).
   - Features 4 distinct tabs (Ledger, Analytics, Gemini AI, Account & Database).
   - Includes Back buttons for login and AI agent, plus masked credentials.

2. **`style.css`**:
   - Clean, modern, vanilla CSS with CSS Custom Properties for theme tokens.
   - High-contrast Dark & Light mode palettes.
   - Full-display responsive CSS Grid and Flexbox layouts.
   - Glassmorphism effects, custom scrollbars, and mobile frame emulation mode.

3. **`app.js`**:
   - Pure, zero-dependency ES6+ JavaScript.
   - **Gemini 2.5 Voice AI Advisor**: Voice recognition (Microphone) & Speech synthesis (TTS) answering:
     - *"Can I buy dinner tonight?"*
     - *"How much money had I spent on transport?"*
     - *"Can I buy 4000$ headphones?"*
     - *"Saving suggestions"*
   - **Balance Options**: Both Auto-calculated balance and Manual balance override.
   - **Savings Goals**: Goal tracking with progress bar and celebratory confetti.
   - **Reminders**: Scheduled budget due-date reminders.
   - **Mobile SMS & NotificationListener Bridge**: Native WebOTP listener, 1-tap clipboard sensor, and quick UPI alert simulator.
   - **Analytics & Graphs**: Category spend SVG donut chart, 7-day spend bars, 50/30/20 rule audit.
   - **Safe Log Out**: Removes active session from device while preserving all data in the database.

4. **`Campus_Ledger_Latest.html`**:
   - The compiled standalone single-file version of the React application with all assets inlined.

---

## 🚀 How to Run

Simply **double-click `index.html`** in this folder to open it in any web browser (Chrome, Edge, Safari, Firefox).  
**No Node.js, no terminal commands, and no web servers are required!**
